# StudentOS 🎓⚡

> A unified, high-performance academic operating system and mobile companion built for university students. Manage schedules, coursework pipelines, real-time attendance thresholds, study vaults, and context-aware academic AI guidance in one unified ecosystem.

## 🌟 Features

- **Dynamic Routine & Timetable**: Automated weekly lecture scheduler with dynamic updates, room allocations, and `.ics` auto-sync export to Google Calendar.
- **Attendance & Threshold Monitoring**: Real-time projection tracking designed to enforce university attendance limits (e.g., 75% policy).
- **Coursework & Exam Pipelines**: Kanban-style task tracking and milestone reminders integrated with course syllabi.
- **Unified Academic Vault**: Centralized previewer and repository for lecture slides, notes, and references.
- **StudentOS Intelligence (AI Copilot)**: Grounded assistant powered by Google Gemini with live context into course deadlines, timetables, and academic performance.
- **Cross-Platform Experience**: Responsive Vite web application paired with an Expo React Native mobile wrapper featuring native pull-to-refresh, safe-area adaptation, and hardware back-button handling.
